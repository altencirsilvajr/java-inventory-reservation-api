# Processo de desenvolvimento

- Trabalhar em incrementos verticais, atômicos e reversíveis na branch `main` deste laboratório.
- Cada commit substantivo não-merge inclui exatamente um Journal.
- Cada Journal declara se cria um ADR, aplica um ADR existente ou não requer ADR.
- Criar ADR somente para decisões duráveis, surpreendentes e com trade-offs reais.
- Manter a SDD ativa coerente com o comportamento implementado.
- Desenvolver mudanças de comportamento em ciclos red-green pelo seam público.
- Registrar somente comandos e resultados realmente observados.
- Preservar os commits atômicos na entrega e publicar cada incremento aprovado.
